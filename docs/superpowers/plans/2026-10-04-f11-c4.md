# F11-C4 Implementation Plan

> **For agentic workers:** Use inline execution with review checkpoints. Steps use checkbox syntax for tracking.

**Goal:** Give each committed incoming XDND Drop a renewable 60-second progress lease bounded by an immutable 10-minute lifetime cap.

**Architecture:** Keep terminal deadlines on the exact `AwaitingWaylandFinish` session. Centralize identity and phase checks in one terminal-layer progress helper, call it only from validated transfer events, and reuse the existing canonical cancellation/fallback path. Retain productive terminal interoperability at XDND v5 and above.

**Tech Stack:** Rust, x11rb fake-X harness, synthetic monotonic timestamps, Cargo.

## Global Constraints

- Keep the renewable lease at `60_000_000_000` ns and the absolute cap at `600_000_000_000` ns.
- Keep `INCOMING_DND_IDLE_TIMEOUT_NS` at 30 seconds and independent of terminal lifetime.
- Only exact, validated live-transfer activity may renew an uncancelled terminal lease.
- Preserve canonical `CancelAfterDrop`, queued `SourceFinished` precedence, one-shot Finished, root-loss survival of committed work, Move DELETE bounds, and generation teardown.
- Keep v5 as the minimum productive reverse-XDND terminal version; do not start F11-D.
- Work on `main`, preserve unrelated worktree state, and use `/mnt/Aether/Desktop/GitHub/Typhon-target` for every Cargo output.

## File map

- `src/xwayland/xwm/data_bridge/dnd_incoming.rs`: terminal phase deadline fields and lifetime constants.
- `src/xwayland/xwm/data_bridge/dnd_incoming/terminal.rs`: exact-session progress authority, hard-cap expiration, cancellation fallback, and terminal deadline scheduling.
- `src/xwayland/xwm/data_bridge/dnd_incoming/transfer.rs`: progress observations after successful admission, validated replies, and positive writes; reject stale pending-reply identity before consuming payload.
- `src/xwayland/xwm/data_bridge/dnd_incoming/tests/terminal.rs` and `tests/terminal_progress_tests.rs`: exact-deadline fake-X regressions for lease renewal, invalid/no progress, hard cap, cancellation, v4, root loss, and cycle ordering.
- `src/xwayland/xwm/data_bridge/dnd_incoming/tests.rs`: reuse the existing exact transfer and fake wire helpers; change only if a focused helper is necessary.
- `docs/XWAYLAND.md`: C4 policy, progress classes, independent timeout, root-loss semantics, v5 boundary, and F11-D boundary.
- `docs/superpowers/specs/2026-10-04-f11-c4-design.md` and `docs/superpowers/plans/2026-10-04-f11-c4.md`: approved design and implementation sequence.
